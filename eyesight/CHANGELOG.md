# 更新日志

## 1.1.0（2026-11-11）

- 新增：看大图。`sight_see({image:"路径"})` 支持 PNG / JPG / WEBP / GIF / TIFF / BMP，图片走和屏幕一样的「地图 + 按块 1:1」流程，图再大也不会糊，只是块数变多。
- 新增：`image` 可以直接给聊天里那张图的 sha256（去 `.dsh/attachments` 找），也支持 `file://` 前缀；新增解码脚本 `scripts/openimg.ps1`。
- 新增：图片帧可 `refresh:true` 重新打开。
- 规则调整：给 AI 写明「先用系统自带取图，只有看不清、读不准的地方才用本插件取块核对」——按需核对大幅省 token（整屏逐块约 7364，核对一处约 1349）。
- 文档：补「动态视场」「图片也一样」「什么时候该用」三节；修正默认模式说明（带 `image` 时第一次会自动给地图）。

## 1.0.0（2026-11-10）

- 首个版本：整屏缩略地图 + 按块 1:1 看清；`sight_fonts` / `sight_check` 精确识别；界面小眼睛开关；`traced` / `direct` 两种模式；每次调用写 `audit.jsonl`。
