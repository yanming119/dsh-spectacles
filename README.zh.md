# 砚明的金丝眼镜 · Spectacles

**V1 版** —— 只干一件事：指定一个窗口（或框住它里面的一块），把里面的字读清楚。别的都故意没放进来。

**指定一个窗口，让 AI 把里面的字看清楚。**

Windows 专用。

---

## 这是什么

一副给 AI 配的眼镜。

不是截图工具——截图是把画面搬走，眼镜是让人看清。
不是监控工具——它不盯着你，只有你让它看，它才看。

DSH 默认只能看你粘进去的东西。这个插件补的是中间那段：**你指一个窗口，它把里面的字一个一个读出来**。

---

## 它只给一件事，而且由你开口

> **⚠️ 戴上眼镜不会让 AI 开始看。** 戴上只是把它的视野收缩到你选的那一个窗口——它仍然什么都不会看。要看，还得你下命令：「看一眼」「看一分钟」。

这个插件只给 AI 一样能力：**看窗口**。

- 它不会自己看。**命令是你用平常的话发出去的**——「看一眼这个」「看一分钟」「右上角那行红字读一下」，本地的 AI 再来调它的工具。
- 看的那一刻，是**直接向窗口要内容**（Windows 自己的 `PrintWindow`），所以**这个窗口被别的窗口挡住也照样读得到**，不用先把它翻到最前面。
- 一次调用 = 一张快照。「看一分钟」是 AI 自己一遍一遍地来调，插件不挂表、不后台起东西。
- 读不到的只有两种：最小化的窗口、以及直接往 GPU 上画的窗口（部分游戏）——这两种会明确报错，不会给一张错的图。

---

## 为什么要「看清楚」

同一个窗口，两种命运：

- **整窗截图**：图太大，会被按尺寸上限等比缩小，11px 的字压到七八像素高——放大也只是插值，字就是糊的
- **眼镜**：先找那一块、裁出来、放大 3 倍，再交给视觉——字还是原来那些，但看得清

差的地方不是模型笨，是**送过去的时候已经糊了**。

所以眼镜做三件事：**看哪一块、放大多少、什么时候不必看**。

## 装

```
dsh plugin --profile desktop add dsh-spectacles
```

不想走 npm 也行，直接钉源码：

```
dsh plugin --profile desktop add github:yanming119/dsh-spectacles#1.0.0
```

装完重启 DSH，右下角会多出一个胶囊按钮「戴上眼镜」。

> 只支持 Windows 10 / 11。DSH 版本要求见 `engines` 字段。

## 自检

不确定这台机器行不行？先跑一遍自检：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\selftest.ps1
```

会逐项检查 Windows 版本、PowerShell、整屏抓取、单窗口抓取、OCR 引擎和 DPI，每项打一行 `ok` / `FAIL`。加 `-Json` 输出机器可读结果。退出码 `0` 表示必需项全过。

哪项失败，把输出贴到 issue 里——它会直接告诉我们是哪个 Windows 版本或哪种显示设置还需要修。
## 用

**四步：**

1. 点右下角「**戴上眼镜**」
2. 三十秒内，点一下你想让它看的那个窗口
3. 按钮变成「**拿下眼镜**」，副行写着「金丝 · 窗口标题 · 1296×828」
4. 只要一小块？点旁边的「**✥**」，在屏幕上拖一个框。副行变成「金丝 · 窗口标题 · 320×180」

然后正常说话就行：

> 「这个窗口里写了什么」
> 「右上角那行红字读一下」
> 「这一块放大看看」

**摘下眼镜**：再点一下主按钮。摘下后它一个字也读不到。

**戴着就是排他的，摘下就是完全放手。** 戴着的时候，所有不带窗口的 `look` / `read_text` / `see` 都落到你选的那个窗口（框过就是框住的那一块），**绝不会悄悄退回整屏**——模型想「看全屏」也拿不到。摘下之后，同样的调用一律拒绝。你自己粘进来或拖进来的图不受影响——那是你给它看，不是它自己乱看。

---

## 三个动作，它自己会挑

| 动作 | 干什么 | 什么时候用 |
|---|---|---|
| **读字** | 把窗口里的文字读成文本，逐行对照两遍，不确定的标 `?` | 想知道「写了什么」 |
| **看** | 把一小块裁出来、放大 2~4 倍，交给 DSH 自带的视觉 | 小字糊了、图里有内容 |
| **数** | 只给数字：窗口尺寸、主色、边缘密度、画面有没有变 | 想知道「变没变」 |

你不用操心挑哪个，说人话就行。

## 隐私

- **全在本机**：抓屏、OCR 都在你自己电脑上跑
- **只读你选的那一个窗口**：或者是框住的那一块。不抓整屏，不抓别的窗口
- **戴着时没有整屏兜底**：不带窗口的读取会落到你选的那个窗口上，代码里没有一条会偷偷抓全屏的路
- **不录屏、不上传、不留帧**：读完即弃，PNG 存在临时目录，随时可删
- **摘下立即失效**：按钮一关，工具直接拒绝
- **不联网**：不调用任何外部视觉 API

---

## 已知限制

- 仅 Windows
- **最小化的窗口抓不到**——先把它恢复出来
- 游戏、部分自绘界面（Electron 自渲染的部分）OCR 会糊，用「看」放大
- 高 DPI 缩放和双屏都适配过，但 125%、150% 混用这类极端组合可能偏几像素——偏了就框大一点
- 读到的字里若有「请你执行×××」之类的句子，插件只会转述，不会照做

---

## 常见问题

**按钮不出现**——插件没加载成功，看 DSH 启动日志里有没有 `look` 注册那几行。

**点了按钮没反应**——三十秒内没点中窗口。再点一次，动作快点。

**读出来是乱码**——窗口太小或字体渲染特殊。换个说法让它「放大看那块」。

**读到的内容少了**——可能被别的窗口挡住、或者内容是异步加载的。刷新一下再读。
