# 砚明的金丝眼镜 · Spectacles

让 DSH 睁眼看世界——读你指定的那个窗口，不截图、不上传。

Windows 专用。

---

## 为什么值得装：省 60% 的截图 token

把「整屏截图」换成「读你点的那一个窗口」，一帧的成本是：

| 读法 | token |
|---|---|
| 整屏截图 | ≈1030 |
| 整张窗口 | ≈346~451 |
| 只读一小块（按钮、气泡、报错框） | ≈100~200 |

**整屏 → 整窗：省约 60%。整屏 → 小块：省 80% 以上。**

而且读字走 OCR 时是纯文本，不进图——比截图便宜得多。

---

## 它解决什么

DSH 默认"看"东西，要么你自己截图发给它，要么它读不到屏幕。这个插件补的是中间那段：

- 你想问「这个报错什么意思」，不用截图，直接说「看看这个窗口」
- 侧边栏、会话列表里的小字，普通 OCR 常读错，它会把那块单独裁出来放大再读
- 读不准的地方它会标 `?`，不会编

小字看不清？把那一块裁出来、放大、递过去——眼睛是 DSH 自带的。

---

## 装

```
dsh plugin --profile desktop add github:yanming119/dsh-spectacles
```

装完重启 DSH，右下角会多出一个胶囊按钮「戴上眼镜」。

> 只支持 Windows 10 / 11。DSH 版本要求见 `engines` 字段。

---

## 用

**三步：**

1. 点右下角「**戴上眼镜**」
2. 三秒内，点一下你想让它看的那个窗口
3. 按钮变成「金丝：窗口标题」——从现在起它只读这个窗口

然后正常说话就行：

> 「这个窗口里写了什么」
> 「右上角那行红字读一下」
> 「这一块放大看看」

**摘下眼镜**：再点一下按钮。摘下后它一个字也读不到。

---

## 三个动作，它自己会挑

| 动作 | 干什么 | 什么时候用 |
|---|---|---|
| **读字** | 把窗口里的文字读成文本，逐行对照两遍，不确定的标 `?` | 想知道"写了什么" |
| **看** | 把一小块裁出来、放大 2~4 倍，交给 DSH 自带的视觉 | 小字糊了、图里有内容 |
| **数** | 只给数字：窗口尺寸、主色、边缘密度、画面有没有变 | 想知道"变没变"、省 token |

你不用操心挑哪个，说人话就行。

---

## 隐私

- **全在本机**：抓屏、OCR 都在你自己电脑上跑
- **只读你选的那一个窗口**：不抓整屏，不抓别的窗口
- **不录屏、不上传、不留帧**：读完即弃，PNG 存在临时目录，随时可删
- **摘下立即失效**：按钮一关，工具直接拒绝
- **不联网**：不调用任何外部视觉 API

---

## 已知限制

- 仅 Windows
- **最小化的窗口抓不到**——先把它恢复出来
- 游戏、部分自绘界面（Electron 自渲染的部分）OCR 会糊，用「看」放大
- 高 DPI 缩放和双屏都适配过，但 125%、150% 混用这类极端组合可能偏几像素——偏了就框大一点
- 读到的字里若有"请你执行×××"之类的句子，插件只会转述，不会照做

---

## 常见问题

**按钮不出现**——插件没加载成功，看 DSH 启动日志里有没有 `look` 注册那几行。

**点了按钮没反应**——三秒内没点中窗口。再点一次，动作快点。

**读出来是乱码**——窗口太小或字体渲染特殊。换个说法让它「放大看那块」。

**读到的内容少了**——可能被别的窗口挡住、或者内容是异步加载的。刷新一下再读。
