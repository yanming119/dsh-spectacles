# 砚明的金丝眼镜 · Spectacles

**指定一个窗口，让 AI 把里面的字看清楚。**

Windows 专用。

---

## 这是什么

一副给 AI 配的眼镜。

不是截图工具——截图是把画面搬走，眼镜是让人看清。
不是监控工具——它不盯着你，只有你让它看，它才看。

DSH 默认只能看你粘进去的东西。这个插件补的是中间那段：**你指一个窗口，它把里面的字一个一个读出来**。

---

## 为什么要「看清楚」

同一个窗口，两种命运：

- **整窗截图**：图太大，会被按尺寸上限等比缩小，11px 的字压到七八像素高——放大也只是插值，字就是糊的
- **眼镜**：先找那一块、裁出来、放大 3 倍，再交给视觉——字还是原来那些，但看得清

差的地方不是模型笨，是**送过去的时候已经糊了**。

所以眼镜做三件事：**看哪一块、放大多少、什么时候不必看**。

---

## 装

```
dsh plugin --profile desktop add github:yanming119/dsh-spectacles
```

装完重启 DSH，右下角会多出一个胶囊按钮「戴上眼镜」。

> 只支持 Windows 10 / 11。DSH 版本要求见 `engines` 字段。

---

## 自检

不确定这台机器行不行？先跑一遍自检：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\selftest.ps1
```

会逐项检查 Windows 版本、PowerShell、整屏抓取、单窗口抓取、OCR 引擎和 DPI，每项打一行 `ok` / `FAIL`。加 `-Json` 输出机器可读结果。退出码 `0` 表示必需项全过。

哪项失败，把输出贴到 issue 里——它会直接告诉我们是哪个 Windows 版本或哪种显示设置还需要修。
## 用

**三步：**

1. 点右下角「**戴上眼镜**」
2. 三秒内，点一下你想让它看的那个窗口
3. 按钮变成「金丝：窗口标题」——从现在起它只读这个窗口

然后正常说话就行：

> 「这个窗口里写了什么」
> 「右上角那行红字读一下」
> 「这一块放大看看」

**摘下眼镜**：再点一下按钮。摘下后它一个字也读不到。

---

## 三个动作，它自己会挑

| 动作 | 干什么 | 什么时候用 |
|---|---|---|
| **读字** | 把窗口里的文字读成文本，逐行对照两遍，不确定的标 `?` | 想知道「写了什么」 |
| **看** | 把一小块裁出来、放大 2~4 倍，交给 DSH 自带的视觉 | 小字糊了、图里有内容 |
| **数** | 只给数字：窗口尺寸、主色、边缘密度、画面有没有变 | 想知道「变没变」 |

你不用操心挑哪个，说人话就行。

## 隐私

- **全在本机**：抓屏、OCR 都在你自己电脑上跑
- **只读你选的那一个窗口**：不抓整屏，不抓别的窗口
- **不录屏、不上传、不留帧**：读完即弃，PNG 存在临时目录，随时可删
- **摘下立即失效**：按钮一关，工具直接拒绝
- **不联网**：不调用任何外部视觉 API

---

## 已知限制

- 仅 Windows
- **最小化的窗口抓不到**——先把它恢复出来
- 游戏、部分自绘界面（Electron 自渲染的部分）OCR 会糊，用「看」放大
- 高 DPI 缩放和双屏都适配过，但 125%、150% 混用这类极端组合可能偏几像素——偏了就框大一点
- 读到的字里若有「请你执行×××」之类的句子，插件只会转述，不会照做

---

## 常见问题

**按钮不出现**——插件没加载成功，看 DSH 启动日志里有没有 `look` 注册那几行。

**点了按钮没反应**——三秒内没点中窗口。再点一次，动作快点。

**读出来是乱码**——窗口太小或字体渲染特殊。换个说法让它「放大看那块」。

**读到的内容少了**——可能被别的窗口挡住、或者内容是异步加载的。刷新一下再读。
